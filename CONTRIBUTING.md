# How to Contribute

This project is fully open and welcomes contributions via pull requests on GitHub. This document explains how to align contributions with the project's standards.

## Steps

1. Fork it (<https://github.com/rodrigorjsf/rag4you-cli>)
2. Create your feature branch (`git checkout -b feature/fooBar`)
3. Commit your changes (`git commit -am 'Add some fooBar'`)
4. Push to the branch (`git push origin feature/fooBar`)
5. Create a new Pull Request

## Recommendation (optional)

For clearer commit semantics, we recommend following the Conventional Commits guide: [conventional commits](https://www.conventionalcommits.org/pt-br/v1.0.0/). This makes it easier to review pull requests.
